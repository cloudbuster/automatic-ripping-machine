This sends every identified DVD in your database to the community ARM database, so other people's ARM can name the same discs without a lookup. Sent per disc: its CRC64, title, year, IMDb ID, label and whether the title was confirmed. Nothing about you is sent, but it does go to an outside service (1337server.pythonanywhere.com).

It needs an ARM database API key in arm.yaml (ARM_API_KEY), and takes long with many discs.
